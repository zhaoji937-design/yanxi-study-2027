# 研习 · 厦门大学2027考研题库

可独立托管的 HTML / CSS / JavaScript 网页，支持手机和平板浏览器、主屏幕入口和离线查题。

网站：[研习](https://yanxi-study-2027.onrender.com)。已由使用者确认 iPhone Safari 在关闭 VPN 时可以打开。

内置694道题：346体育综合610道（名词解释358、简答237、论述15）、政治56道、英语（二）28道。可按教材、章、节筛选，直接展开答案核对，无需逐题提交。

专业课610条已重新整理。358条名词解释以用户提供的三本教材定义段原图为主，点击即放大，可左右滑动；校对文字可展开复制。核对要点仅为记忆关键词，辅助解释统一放在“思路与易错提醒”。237条简答、15条论述按题干分项展开，正文是依据教材组织的参考作答。37条没有独立定义的旧名词保留原ID与知识点，改为相应简答。原有27道逐页核对示范的复习辅助和历年题关系保留。题库未穷尽全部可考内容，参考答案不是官方评分细则。

237条简答现默认显示可直接背诵的编号要点，一点一层意思；正文移除“教材指出”等教学说明，保留条件、比较、因果和必要例子。关键术语在正文内使用深绿色与加粗，避免仅靠颜色识别。需要补充时可展开详细答案；审题核对按每题配置对象、任务、范围和覆盖检查，默认折叠。备份包含精简答案、详细答案、记忆词与审题资料。名词解释和论述不受这轮改写影响。

入口：[怎么背与怎么答](https://yanxi-study-2027.onrender.com/#study)、[历年题与排除依据](https://yanxi-study-2027.onrender.com/#papers)。

历年题索引有51条记录：2026年第三方转录27条，2025年回忆24条；其中5条仅有主题，题干不完整，不参与任何自动排除。未取得官方原卷，2022—2024也未取得可核实的完整题干，不能声称近五年全覆盖。默认“日常 · 排除已考考点”暂不展示73道题库题（39道同术语/等价任务精确匹配＋34道关联考点）；可切换“仅排除已考原题”（39道）、“全部题目”或“已考原题 · 有来源”。关联考点不等于原题重复，筛选仅用于安排练习，题目没有删除，**不能据此认为考过的以后不会再考**。每条对应关系和理由可在历年题页面查看。

独立的英语易混词工具“词辨”：<https://yanxi-study-2027.onrender.com/words/>（绕过旧缓存的更新入口：`/words/latest.html`）。5721词可查、119组原创重点辨析、325道原创语境题；字形和音近候选可连续多选，自动带上当前查词，最多32词一起对照或保存为自建组。候选各最多24词，支持跨字形、读音和查词结果累积选择。手机分行、平板分栏，可遮住中文、复习与备份。它与原题库使用独立存储和离线缓存。设备朗读依赖浏览器的英语语音。

词库保留原3600词，合并 [exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary) 的5530条考研词表（大小写同词合并为5528项），再补词族；不导入其不可靠的异体拼写字段、自动例句或跨考试词频。该第三方词表以2024版为基础，未声称逐词核对2027官方大纲。默认显示考研整理释义，补充词显示通用义，330个多义/易混及基础功能词另有原创阅读选义与搭配；完整 ECDICT 释义折叠，基础词典未逐词人工审订。衍生 `dist/words/data.json` 与 `content/word-exam-base.json` 按 **CC BY-NC-SA 4.0** 共享，保留署名、修订说明与完整许可；本站为非商业学习工具。ECDICT（MIT）与 CMUdict（BSD类许可）的许可证仍独立保留。自动候选仅为查找线索。版本、数量与许可见 `content/words-source-summary.json`、`dist/words/licenses/`。

参考作答是依据指定教材整理的答案与应用组织，并非官方评分标准。教材引用显示印刷页码，未包含原教材PDF。

## 运行和部署

- 静态文件位于 `dist/`，所有页面依赖均为同目录文件。
- 构建检查：`node scripts/check-site.cjs`。
- 学习卡生成：`node scripts/build-study.cjs`，读取仓库内的 `content/verified-study-cards.json` 生成 `dist/bank-study.js`。
- 全量修订生成：`node scripts/build-sports-revision.cjs`，读取 `content/sports-revised.json`，校验原文与来源的一致、关键词及全部定义原图引用和内容哈希，生成最终覆盖层 `dist/bank-sports-revised.js`。该覆盖层须在旧题库和学习卡之后加载。
- 定义原图集合：`dist/textbook-images.json`，只包含定义区域与必要上下文，不发布整本PDF。原始扫描件及内部校对脚本不进入仓库。
- 背诵与词辨逻辑检查：`node --test scripts/study.test.cjs scripts/sports-revision.test.cjs scripts/recall-answer.test.cjs scripts/words.test.cjs`。
- Render服务类型：Static Site；Build Command：`node scripts/check-site.cjs`；Publish Directory：`dist`。
- 不需要数据库、后台服务器或AI接口。浏览器访问和离线功能不依赖GPT或原托管平台。

## 学习记录

记录只保存在当前浏览器。更换网站域名、设备或浏览器时，通过“备份与设置”导出和恢复完整备份。新网址不会自动读取原网站的本机记录。

背题位置、回忆自评与到期时间也包含在完整备份中。回忆自评分为“完全没想起、漏了要点、与别的概念混淆、能独立回忆”，按展开答案前的真实表现记录，仅浏览答案不算独立回忆。当前便利排程为：独立回忆后依连续成功次数约1、3、7、14、30天；完全没想起约10分钟；漏点或混淆约30分钟。它用于帮助执行复习，不是唯一科学标准，也不保证每个人的最优间隔或考试成绩。

在“备份与设置”确认显示“离线题库已保存”后，可断网看题、答案和定义原图；首次访问、更新和外部资料链接仍需联网。浏览器清理网站数据会移除记录和缓存，请保留备份。

更新入口：[研习更新版](https://yanxi-study-2027.onrender.com/latest.html)。它与原首页同源，保留原有记录，可绕过旧版首页缓存。新缓存完成后原首页也能使用；新版本首页联网优先更新、断网回退。请勿为更新直接清除网站数据。主站缓存与“词辨”独立。

## 后续更新

修改页面、样式、脚本或题库后，需同步更新 `dist/sw.js` 的缓存版本和资源清单，检查新缓存完整，再发布。本站使用hash路由，不需要把所有文件请求重写为首页；缺失脚本应保持404。

“词辨”文件位于 `dist/words/`；修改它时更新 `dist/words/sw.js` 的专属 `yanxi-words-` 缓存版本。基础词表预处理脚本为 `scripts/build-words.py`，仅本地运行，依赖 rapidfuzz/numpy 以及仓库外的固定版本数据；托管构建直接验证已生成的 JSON，不会下载语料或运行 Python。
