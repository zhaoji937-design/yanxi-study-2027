## 运行和部署

- 静态文件位于 `dist/`，所有页面依赖均为同目录文件。
- 构建检查：`node scripts/check-site.cjs`。
- 学习卡生成：`node scripts/build-study.cjs`，读取仓库内的 `content/verified-study-cards.json` 生成 `dist/bank-study.js`。
- 全量修订生成：`node scripts/build-sports-revision.cjs`，读取 `content/sports-revised.json`，校验原文与来源的一致、关键词及全部定义原图引用和内容哈希，生成最终覆盖层 `dist/bank-sports-revised.js`。该覆盖层须在旧题库和学习卡之后加载。
- 定义原图索引：`dist/textbook-images.json`（version:2），数据位于 `dist/textbook-images/<教材>/<章>-<内容指纹>.json`。只包含定义区域与必要上下文，不发布整本PDF。生成/核验：`node scripts/split-textbook-images.cjs [--check]`；每包大小见 `content/textbook-image-sizes.json`。原始扫描件及内部校对脚本不进入仓库。
- 背诵与词辨逻辑检查：`node --test scripts/study.test.cjs scripts/sports-revision.test.cjs scripts/recall-answer.test.cjs scripts/words.test.cjs`。
- Render服务类型：Static Site；Build Command：`node scripts/check-site.cjs`；Publish Directory：`dist`。
- 常规题库与笔记不需要数据库、后台服务器或AI接口。模拟考试的在线自动评阅使用下述独立服务。

## 模拟考试与在线评阅

入口：`/latest.html#exam?mode=mixed` 三本书综合模拟，`/latest.html#exam?mode=single` 单本书模拟。固定5道名词解释（每道5分）、3道简答（每道15分）、1道论述（30分），合计100分。默认180分钟，开考前可选90或120分钟；这是依用户题型要求自拟的训练卷与评分方案，不是厦大官方卷型或经校准的难度等值测试。

综合卷名词解释按2/2/1分配、简答每本各一题、论述轮换教材。单本卷仅选对应教材。以已核对专业课题为基础抽取，优先跨章和避开最近三卷；不把换问法重复计为新考点。交卷前不显示参考答案。题库直接浏览仍保留原功能。

倒计时依据开考的绝对截止时间，刷新、切后台不重置，无暂停。页面提示15分钟、5分钟、1分钟，到时锁卷；网页关闭时无法保证弹出提示，重新进入仍按原截止时间处理。自动评阅通道开考与评阅必须联网，断网期间锁定输入但计时继续；ChatGPT 网页评阅通道可离线开考、作答和交卷，转交到官网时需联网。文字作答保存在 `yanxi-mock-exams-v1`，不依赖手写笔迹识别。模拟记录、订正、评分结果和签名答卷包含在完整备份中，也可单独导出；旧完整备份不含该字段时保留当前模拟记录。

前端配置为 `dist/exam-config.json`，后端为 `server/exam-server.cjs`（Node22+，无额外依赖）。API独立部署，保留原前端域名与所有本机学习记录；CORS仅允许配置的前端，浏览器会话只持有个人考试访问口令，不接收或保存OpenAI API密钥。

后端环境变量：

- `OPENAI_API_KEY`：由使用者在服务环境变量界面填写，仅服务器使用，不能放进源码、前端配置、聊天或浏览器。
- `OPENAI_MODEL`：默认 `gpt-5.4`，使用Responses、high reasoning及strict JSON Schema，`store:false`。
- `EXAM_ACCESS_CODE`：使用者设置至少12位个人考试访问口令，在网页首次连接时输入。
- `EXAM_SIGNING_SECRET`：至少32字符随机签名密钥，部署时生成；修改会使旧考试凭证失效。
- `EXAM_ALLOWED_ORIGINS`：默认 `https://yanxi-study-2027.onrender.com`。
- `EXAM_DAILY_LIMIT`：默认8次评阅尝试/日；另有限制并发和每小时尝试次数，防止意外重复调用。

未配置有效API密钥、口令及签名密钥时，服务明确返回未就绪，不允许自动评阅考试开考，也不制造分数。OpenAI API单独计费，ChatGPT网页登录或订阅不能代替接口配置。免费Render服务可能休眠，界面允许等待和重新连接；启动命令为 `node server/exam-server.cjs`，健康检查 `/api/health`。

自动模式服务器签发试卷并确认时间；作答同步得到HMAC签名检查点，超时后只接收服务器在截止前确认的内容，不接收后来补写的答案。签名凭证随本机备份保留，服务重启仍可校验；评阅任务短期存内存，服务重启后可凭已锁定答卷重试，已完成报告保存在浏览器。原始答案锁定后，订正独立保存，不修改成绩。

评阅逐项给分、引用学生原句，标记明确错误、具体漏点、存疑之处与修改办法，并提供完整修订作答及教材印刷页码。程序核对试卷号、冻结答卷SHA256、所有题号及评分项，检查分数范围/0.5分步长/空白题0分/逐项相加一致，并拒绝答卷中不存在的引用。失败、额度不足、refusal、incomplete或格式错误均不显示伪造分数。成绩是本卷模拟估分，不推算正式考试必得分。

手动通道可离线完成考试，交卷后默认“自己批改”，对照原始作答和逐项评分要点，用快捷档位或数字框打分。也可展开“让 GPT 批改”，复制纯文字材料到已经打开的任意GPT对话，再粘贴回复回来；不打开外站，不要求评分JSON。每题得分宽松识别，缺失可手填、已有可修改，确认后总分由研习相加，完整回复以纯文字保存。新lite评分与原JSON评分继续混合读取，来源明确标注为自评/GPT文字批改。网页不会读取其他网站的登录或对话。

检查：`node --test scripts/exam.test.cjs` 包含卷型、分值、签名/超时、服务重启、结果校验与未配置拒绝等。自动化浏览器覆盖手机/iPad宽度、刷新恢复、断网锁定、倒计时、交卷、评分导入、订正和备份；测试传输使用夹具，不代表真实OpenAI接口已配置或评分质量已校准。正式API联调须在使用者配置有效密钥及额度后进行。

## iPad阅读与手写批注

主导航改为主动打开的抽屉，关闭不重新渲染正文；知识树的本节目录/题目列表可单独隐藏，iPad默认收起。专注阅读隐藏页头、搜索与标题路径，保留视图切换及退出按钮。目录与专注偏好保存在 `yanxi-knowledge-ui-v1`。

导图支持双指围绕指间中心缩放、单指原生滚动、Safari手势事件回退及Ctrl+滚轮缩放；缩放范围35%—250%，缩放不重建导图、不跳回选中节点，手势结束抑制误触标题。

正文批注改为覆盖整张阅读卡片的连续矢量层，可在正文、段间及卡片内的边缘空白书写，不再把每一笔限制在段落框内。落笔使用本次书写开始时的固定坐标；新笔迹整体依附段落，不逐字重新定位、不因边界自动移动。书写期间只更新当前笔迹，不重画旧笔迹、不扫描字符；抬笔后保存。旧版按文字/空白定位的笔迹保持兼容渲染。

画笔放入可拖动、可收起的非模态浮窗，含签字笔、钢笔、铅笔、马克笔、荧光笔及橡皮。每种笔独立记忆0.5—30px粗细、5%—100%浓淡与任意六位HEX颜色，实时显示预览。各笔型使用不同的曲线、轮廓或纹理画法；这不是调用苹果原生PencilKit，也不包含手写识别、自动美化和套索。设置保存在 `yanxi-ink-tools-v1`；每笔自己的笔型、颜色、粗细和浓淡随完整备份保存。

按用户选择，默认普通电容笔模式：单指/普通电容笔书写，双指移动页面；第二个触点进入时撤回当前临时笔迹（含尚未提交的橡皮操作），手势结束后不留下误写。普通电容笔若被浏览器报告为touch，无法可靠与手指自动区分，也不能承诺原生防掌触或真实压感。浮窗另有“手写笔专用”，只接受可识别的pen输入（电脑允许鼠标），手指保留原生滑动。

“调整留白”显示每段的加、减和一键收起，调整无需撤销笔迹。缩减保留已有笔记所需的最低高度并显示提示，防止把笔迹裁掉；擦除后可一键收起剩余留白。橡皮和留白变更都能撤销。

笔迹仍保存于独立 `yanxi-ink-v1`，以知识点/题号及原段落文本定位；新旧笔迹可混存，备份格式version仍为1，新增笔型、浓淡及paragraph定位为可选字段。新笔迹在重排时整体随段落移动，保留手写字内部的相对位置；窄屏超出卡片部分仅显示裁切，不改写数据。源段落改变不自动贴到新文字，原数据保留在备份中。

每笔结束及退出前保存，存储失败明确显示未保存并可导出内存中批注。完整备份包含矢量笔迹、定位文本与空白高度；恢复前严格校验，失败不写入。旧备份无批注字段时保留当前批注，重置答题记录也保留批注。设备/浏览器不自动同步，需完整备份转移；清理网站数据会移除本机笔记。数据与定位测试：`node --test scripts/ink.test.cjs`。

## 学习记录

记录只保存在当前浏览器。更换网站域名、设备或浏览器时，通过“备份与设置”导出和恢复完整备份。新网址不会自动读取原网站的本机记录。

背题位置、回忆自评与到期时间也包含在完整备份中。回忆自评分为“完全没想起、漏了要点、与别的概念混淆、能独立回忆”，按展开答案前的真实表现记录，仅浏览答案不算独立回忆。当前便利排程为：独立回忆后依连续成功次数约1、3、7、14、30天；完全没想起约10分钟；漏点或混淆约30分钟。它用于帮助执行复习，不是唯一科学标准，也不保证每个人的最优间隔或考试成绩。

在“备份与设置”确认显示“离线题库已保存”后，可断网看题、答案和定义原图；首次访问、更新和外部资料链接仍需联网。浏览器清理网站数据会移除记录和缓存，请保留备份。

更新入口：[研习更新版](https://yanxi-study-2027.onrender.com/latest.html)。它与原首页同源，保留原有记录，可绕过旧版首页缓存。新缓存完成后原首页也能使用；新版本首页联网优先更新、断网回退。请勿为更新直接清除网站数据。主站缓存与“词辨”独立。

## 后续更新

修改页面、样式、脚本或题库后，需同步更新 `dist/sw.js` 的缓存版本和资源清单，检查新缓存完整，再发布。本站使用hash路由，不需要把所有文件请求重写为首页；缺失脚本应保持404。

“词辨”文件位于 `dist/words/`；修改它时更新 `dist/words/sw.js` 的专属 `yanxi-words-` 缓存版本。基础词表预处理脚本为 `scripts/build-words.py`，仅本地运行，依赖 rapidfuzz/numpy 以及仓库外的固定版本数据；托管构建直接验证已生成的 JSON，不会下载语料或运行 Python。
